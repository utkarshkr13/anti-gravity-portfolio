SAP tracker — project notes

The problem

Integration testing involved SAP and Salescode teams. Results and pending actions were scattered across spreadsheets, making it hard to see what was ready and what needed attention.

What I built

A shared web tracker for test entries, API readiness, and sign-offs. JavaScript and Firebase handle the application and data, with Clerk for authentication and Chart.js for progress views.

The approach

The tracker keeps testing information together so teams can review the same status rather than reconcile separate updates.

Escalation portal — project notes

The problem

Managing escalations through email made ownership, deadlines, and previous follow-ups difficult to see together.

What I built

A ticket portal with Gmail integration, assignment routing, internal notes, and reminders. The application uses Next.js and TypeScript, with PostgreSQL and Prisma for ticket data.

The approach

Keeping internal notes separate from client communication gives the team room to coordinate while maintaining a clear view of each ticket.
